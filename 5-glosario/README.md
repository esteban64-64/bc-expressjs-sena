# Glosario — Semana 01: Node.js Fundamentals

## Términos clave

| Término | Definición |
|---------|------------|
| **Runtime** | Entorno de ejecución que interpreta y ejecuta código JavaScript fuera del navegador. |
| **Event Loop** | Mecanismo que permite a Node.js realizar operaciones I/O de forma no bloqueante. |
| **I/O no bloqueante** | Modelo donde el hilo principal no se detiene esperando operaciones de entrada/salida. |
| **ES Modules (ESM)** | Sistema de módulos nativo de JavaScript usando `import`/`export`. |
| **CommonJS (CJS)** | Sistema de módulos tradicional de Node.js usando `require`/`module.exports`. |
| **Callback** | Función pasada como argumento para ejecutarse después de una operación asíncrona. |
| **Promise** | Objeto que representa la eventual finalización (o falla) de una operación asíncrona. |
| **Async/Await** | Sintaxis que permite escribir código asíncrono de forma secuencial y legible. |
| **TypeScript** | Superset tipado de JavaScript que compila a JavaScript. |
| **tsconfig.json** | Archivo de configuración del compilador TypeScript. |
| **strict mode** | Modo de TypeScript que habilita todas las verificaciones de tipo estrictas. |
| **fs/promises** | API de filesystem de Node.js basada en promesas (versión moderna). |
| **Path resolution** | Proceso de resolver rutas de archivos de forma relativa o absoluta. |
| **JSON.parse()** | Método para convertir una cadena JSON en un objeto JavaScript. |
| **Interface** | Estructura de TypeScript que define la forma de un objeto. |
