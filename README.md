## 🚀 Cómo ejecutar todo

```bash
# Instalar dependencias
pnpm install

# Ejercicio 01
pnpm ex01

# Ejercicio 02
pnpm ex02

# Proyecto SENA (sin filtro)
pnpm dev

# Proyecto SENA (con filtro por categoría)
pnpm dev -- --category activo

# Compilar TypeScript
pnpm build
```
